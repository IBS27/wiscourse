Project 2: Multithreaded Web Server — Handout

Updated Aug 14 by Arpaci-Dusseau · first viewed today

In this project you will turn a single-threaded web server into a multithreaded one using a fixed-size thread pool and a bounded buffer. Start from the p2-starter.tar.gz · 48 KB and read Lecture 10: Threads API first.

Overview

The server receives requests on a listening socket. A master thread accepts connections and places them in a buffer; worker threads pull from the buffer and serve the request. Your buffer must be protected with a lock and two condition variables — empty and fill.

Scheduling policies

  • FIFO — serve in arrival order.
  • SFF — smallest file first. Requires a stat() in the master.
prompt> ./wserver -d basedir -p 8003 -t 8 -b 16 -s SFF

Grading

Submit through the Project 2 assignment before Friday. Late policy is in the syllabus. Questions go to Piazza.

Search model (all variants)
  • Query ≤ 1 char → actions + recents (B).
  • Prefix #code or pick a course chip → scoped (C). Course pages open ⌘K pre-scoped.
  • Groups only render when non-empty; ≤ 3 per group, "show all" expands.

  • Items you've never opened show a course-colour dot; seen items don't.
  • Scope ⌘K to Convex-cached lists — no server round trip while typing.

On mobile the course header collapses into the nav bar; the Canvas link and search sit top-right. Search is a sheet, not a palette — no ⌘K to press.

Decisions to make

Course hub shell

A tabs+header · B sub-rail · C compact bar.
A is the safest; C gives the reader the most room; B makes pinned items possible.

Modules

Accordion (1A) · list→page (2B) · timeline (2C).
Accordion matches Canvas muscle memory. Timeline needs dated modules.

Files

Three-pane (4A) · single column (4B) · search-first (4C).
4A on desktop, 4B on mobile is the natural pairing.

Inbox

Rows (6A) · split (6B) · by course (6C).
6B avoids a route per feed item; 6A is denser and keeps one card component with Home.

⌘K

Grouped (7A) · tabs+recents (7B) · scoped+preview (7C).
These layer: B's empty state, A's grouping, C's scope chip.

Shared

Unread dot in course colour everywhere (module items, file rows, tabs, ⌘K). Link styling: solid = external, dotted = internal, chip = file.
